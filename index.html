How the calculations work

Input / Output / Cache Tiers

Baseline values match Cursor’s models & pricing docs. Fast and Auto modes appear as separate rows. Enabling High simulation in this dashboard applies \( \phi = 1.50 \) across Input, Cache Write, Cache Read, and Output for what-if math only — it is not Cursor Fast mode.

Cost Multiplier Factor (\(M\))

The pricing multiplier indicates how expensive a model's base input rate is compared to the baseline rate (\( C_{base} = \$1.25 \) per 1M tokens): $$M = \frac{C_{input}}{C_{base}}$$ Values less than \( 1.0\times \) highlight budget-favorable processing states.

Simulated Cost (\(S_{cost}\))

Determined dynamically by matching custom slider inputs for Input Tokens (\(T_{in}\)), Output Tokens (\(T_{out}\)), and Cache Match Ratio (\(R_{cache}\)): $$S_{cost} = \frac{T_{in}}{10^6} \left[ (1-R_{cache})C_{in} + R_{cache}C_{read} \right] + \frac{T_{out}}{10^6}C_{out}$$ When Cursor publishes no cache-read rate, the simulator applies the standard input rate to cached tokens instead of treating them as free.

Balance Tier Score (\(E_{overall}\))

Scores utilize a composite rating system combining raw capabilities and resource footprints: $$E_{overall} = (B_{swe} \times 0.65) + \left( \left(1 - \frac{\min(M, 15)}{15}\right) \times 100 \times 0.35 \right)$$ Tier badging corresponds dynamically:
S-Tier (\(\ge 93\)), A-Tier (\(88\text{--}92\)), B-Tier (\(80\text{--}87\)), C-Tier (\(< 80\)).
